<h2 id="项目动机">
  <img src="./template/imgs/icon/motivation.png" width="25" /> 项目动机
</h2>

学术海报是展示研究成果、交流研究观点的重要媒介。一张结构清晰、重点突出、视觉协调的海报，能够帮助读者在较短时间内理解研究问题、方法和主要发现。然而，许多研究者在海报的版式设计、信息组织和视觉表达方面缺少可直接参考的模板。

本项目旨在提供简洁、规范且易于修改的学术海报模板，帮助研究者快速完成会议展示、学术汇报、墙报交流和课程项目展示。

> **项目特色**：
> - **结构清晰**：围绕研究背景、研究问题、方法、实验结果和结论组织内容。
> - **风格多样**：提供不同配色、版式和信息布局，适配不同研究主题与展示场景。
> - **易于编辑**：模板采用常用编辑工具制作，便于替换文字、图片、图表和二维码。
> - **开源免费**：所有资源免费开放，欢迎社区贡献和优化。

本项目所用徽章、图标和示例素材来自互联网或开源资源。如有版权问题，请联系我们删除或替换，感谢理解。

<h2 id="项目简介">
  <img src="./template/imgs/icon/intro.png" width="25" /> 项目简介
</h2>

本项目提供适用于学术会议、科研汇报和成果展示的海报模板。模板重点覆盖以下内容：

- 研究背景与研究动机
- 研究问题与核心贡献
- 方法框架与技术路线
- 数据集、实验设置与评价指标
- 实验结果、可视化图表与案例分析
- 结论、局限性与未来工作
- 作者信息、联系方式与项目二维码

### 模板示例

目前提供**竖版**和**横板**，并分别提供**蓝色**和**黄色**两种配色，适用于不同的会议展示空间和打印尺寸。

本项目计划提供以下核心资源：

- **PowerPoint 模板**：提供 `.pptx` 格式文件，便于直接编辑文字、图片、图表和布局。
- **横向与纵向版式**：根据会议展板、墙报或打印场景灵活选择海报方向。
- **蓝色与黄色配色**：提供两种视觉风格，方便匹配不同研究主题。
- **示例海报**：提供 SVG 格式预览，帮助用户快速了解模板效果。
- **图标与辅助素材**：用于增强海报的信息层次和可读性。

### 1. 下载模板

终端执行以下命令：

```bash
git clone --depth 1 https://github.com/MLNLP-World/Academic-Poster-Template.git
```

### 2. 选择模板并定制内容

从 `template/pptx/` 中选择合适的 PowerPoint 模板，根据研究内容修改海报中的以下部分：

- **研究背景**：说明研究领域、现实需求和问题来源。
- **研究问题**：用简洁明确的语言突出需要解决的核心问题。
- **方法与技术路线**：使用流程图、架构图或示意图展示方法框架。
- **实验结果**：优先展示关键图表和结论，避免堆叠过多细节。
- **结论与贡献**：概括研究发现、方法优势和实际意义。
- **作者信息**：补充作者、单位、邮箱、项目主页或二维码。

建议在导出前检查海报尺寸、字体可读性、图片分辨率、颜色对比度以及二维码是否能够正常识别。

### 3. 贡献模板

我们欢迎社区贡献新的学术海报模板、版式设计、图标素材或使用建议！请提交 Pull Request 至[GitHub 仓库](https://github.com/MLNLP-World/Academic-Poster-Template.git)。
